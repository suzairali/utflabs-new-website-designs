TickrMeter: an e-ink stock ticker, from prototype to production

TickrMeter is a physical stock ticker that sits on your desk and shows live prices on an e-ink display. UTF Labs worked with the TickrMeter team from prototype to final product: device firmware, the companion app, over-the-air updates, manufacturing test procedures and the cloud platform that connects each device. The result is a product with more than 25,000 devices in use, according to the client's own site.

The challenge

A glance, not another screen

Investors and traders watch the market in different ways. Some want a glance, not another bright screen or another app to open. The device had to show prices clearly, run for weeks on a battery, and keep getting new features after it left the factory.

What we built

Five pieces, one product

01

Firmware for the device

The device runs on an ESP32 controller and drives an e-ink display. E-ink gives no backlight, so the ticker blends in on a desk like a framed picture, and it uses very little power.

02

A companion app and a web interface

Owners register a device online and choose which stocks, crypto or other assets to show. They set price alerts that flash, change colour or sound a buzzer, change how often the ticker updates, and set up several modes for different assets from a phone or a browser.

03

A cloud platform behind every device

The platform registers devices, assigns tickers, and sends price updates to the devices. It uses MQTT for the live data and HTTPS for the rest, with a React management console and a Node.js back end.

04

Over-the-air updates

Firmware updates reach devices without anyone touching them, which is how the product keeps gaining features. The client's site says it receives new features through software and firmware updates.

05

Manufacturing test procedures

We built the quality checks used when the devices are produced, so each unit is tested the same way.
